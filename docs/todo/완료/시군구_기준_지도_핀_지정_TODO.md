# 시군구 기준 지도 핀 지정 및 위치 반환 TODO

## 원칙

- Geolocation API는 필수로 사용하지 않는다.
- 사용자 계정에는 실시간 위치나 상세 좌표를 저장하지 않는다.
- 기본 활동지역은 시군구 단위 행정구역 코드와 표시명으로 `user_location_preferences` 테이블에 별도로 저장한다.
- 위경도 좌표를 데이터베이스에 저장하거나 다룰 때는 JTS Point(경도 x, 위도 y 순서, SRID 4326) 구조를 준수한다.
- 사용자가 선택한 핀의 좌표가 선택한 시군구 행정 경계를 벗어날 경우 검증하여 차단한다.
