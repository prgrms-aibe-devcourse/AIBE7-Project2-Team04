## 개발 원칙

기능마다 `Entity/마이그레이션 → Repository → Service → Controller/DTO → 프론트엔드 → 테스트·문서` 순서로 하나의 세로 흐름을 완성한 뒤 다음 기능으로 이동한다. AI·관리자·신고 같은 후순위 기능보다 회원가입부터 매칭·채팅까지 이어지는 MVP 사용자 흐름을 먼저 완성한다.
